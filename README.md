# 🚀 iebLabs Micro-Tools Collection

A curated collection of fast, privacy-friendly, zero-backend micro web applications designed to solve everyday legal, financial, and organizational problems in seconds.

Built with clean HTML5, Tailwind CSS, and vanilla JavaScript. No trackers, no bloatware, mobile-first.

---

## 🛠️ Included Tools

### 1. [AbfindungsCheck](./01-abfindungscheck)
- **Problem Solved:** Fast severance pay calculation following German labor law (§ 1a KSchG) after receiving a job termination.
- **Key Features:**
  - Standard & custom settlement factor calculation
  - Legal warning timer for the crucial 3-week deadline
  - Tax optimization explanation (Fünftelregelung § 34 EStG)
  - Direct attorney consultation lead flow

### 2. [SpritKostenTeiler](./02-spritkostenteiler)
- **Problem Solved:** Fair, instantaneous travel cost splitting for road trips, festivals, and carpooling.
- **Key Features:**
  - Fuel consumption & price calculation + toll/parking fees
  - Optional vehicle wear & tear allowance (+0.05 €/km)
  - 1-Click WhatsApp group settlement message generator
  - Integrated `PayPal.me` payment link generation

### 3. [KitaPlatzHelfer](./03-kitaplatzhelfer)
- **Problem Solved:** Automatic legal appeal letter generator for parents denied public childcare under § 24 SGB VIII.
- **Key Features:**
  - Formal objection template with strict 14-day legal deadline
  - Loss-of-earnings and private nanny cost reimbursement notices
  - Clean print & clipboard export

## 🚀 Deployment & Usage

All tools are standalone single-page applications. Simply deploy any subfolder to:
- **Netlify / Vercel:** Drag and drop the folder directly into the web dashboard.
- **GitHub Pages:** Enable GitHub Pages in your repository settings and select the `root` or `docs` directory.
